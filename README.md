## Project Overview

The **Airline Sentiment Analysis** project uses Natural Language Processing (NLP) and Machine Learning to analyze customer opinions about airlines through tweets. The project classifies customer feedback into three sentiment categories: **Positive, Negative, and Neutral**.

Using the "C:\Users\ASUS ROG STRIX\OneDrive\Desktop\twitterdataset\Tweets.csv" dataset, the project involves data cleaning, text preprocessing, exploratory data analysis (EDA), feature extraction using TF-IDF, and sentiment classification using machine learning algorithms. The trained model is evaluated using performance metrics such as accuracy, precision, recall, and F1-score.

The project also includes an interactive web application built with Streamlit, allowing users to enter a tweet and receive a predicted sentiment. This helps demonstrate how NLP and machine learning can be applied to understand customer feedback and identify service-related concerns.

**Key objectives:**
- Analyze customer opinions about airlines using tweet data.
- Clean and preprocess text using NLP techniques.
- Convert text into numerical features using TF-IDF.
- Train and evaluate machine learning models for sentiment classification.
- Build an interactive application to predict the sentiment of new tweets.
